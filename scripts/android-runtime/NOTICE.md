# Android local device runtime

Runtime and native executable provenance: Mika, commit
4387bfeace287fafb73038609efcb00ff6a5f63e
https://github.com/wangzan101/Mika/tree/4387bfeace287fafb73038609efcb00ff6a5f63e

Mika application code: Apache-2.0 (copyright the Mika contributors).
libmikarun.so launcher: MIT, Mika contributors.
PRoot 5.4.0: GPL-2.0-or-later; statically linked talloc 2.4.3: LGPL-3.0-or-later.
These are separate subprocess executables, not linked into LambChat.
Alpine runtime component versions and licenses: packages.json in this directory.
Python dependency wheel licenses are retained in their dist-info directories.

The Android release must include android-runtime-sources.tar.gz, generated by
scripts/prepare_android_runtime.py --sources. It includes Mika's pinned source,
native source archives, patches, licenses, and Alpine corresponding source.
Do not distribute an APK without this companion source artifact.

LambChat's runtime ZIP adaptation and launcher bridge are maintained by LambChat.

Android phone-control ADB protocol and ShellContext are adapted from the same
Mika commit under Apache-2.0. Copies of its license and attribution ship in
assets/third-party/mika; source and interoperability tests are retained in the
Android project. ShellContext includes the upstream scrcpy attribution.
