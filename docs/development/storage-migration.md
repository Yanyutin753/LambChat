# 存储迁移验收与保留策略

迁移采用“先复制、再验证、最后切换”。适用于本地目录、Aliyun OSS，以及 AWS / Tencent / MinIO / 自定义 S3 兼容后端。文件 key 不变；不要先改环境变量或删除旧桶。

## 切换步骤

1. 确认所有 API、worker 和其他写入进程均已升级到带迁移保护的版本，旧版本进程已经退出。禁止其他脚本同时直接写源桶或目标桶。多节点本地目录必须是同一共享文件系统。
2. 在服务继续使用旧存储时，将**全部对象**复制到私有目标桶/目录。包括附件、头像、技能文件、缩略图及其他未进入附件索引的对象。保留 key 和必要元数据，目标凭据必须可列举、读取、写入、删除对象。迁移接口不负责复制。
3. 使用具有相应设置管理权限（修改凭据还需 `settings:security`）的账号，调用 `POST /api/settings/storage/migrate`。请求 `changes` 一次提交所有需要修改的连接字段，例如：

```json
{
  "changes": {
    "S3_ENABLED": true,
    "S3_PROVIDER": "aliyun",
    "S3_ENDPOINT_URL": "https://oss-cn-hongkong.aliyuncs.com",
    "S3_BUCKET_NAME": "destination-bucket"
  }
}
```

跨账户时同时提供 `S3_ACCESS_KEY` / `S3_SECRET_KEY`；通过安全客户端传入，不写入命令历史或日志。`S3_REGION`、`S3_PATH_STYLE`、`LOCAL_STORAGE_PATH` 等连接字段也受同一保护。

4. 服务先验证目标可读写和清理临时对象，再穷尽源对象分页，合并已有文件引用，逐文件流式核对字节数和 SHA-256；有原始校验值时还须与原始记录一致。缺文件、损坏、读取失败、权限不足均拒绝切换。返回成功的 `objects` / `bytes` 是实际核验数，不代表仅检查清单。没有 LLM 调用，但全量读取会产生对象请求、流量及可能的低频存储读取费用；大桶请在内网、低峰期从服务直连入口运行，设置足够的客户端超时，不要循环重试。
5. 校验期间普通上传可继续。如果有写入、删除、未完成分片上传或其他配置更新，切换被拒绝，旧存储继续有效。补齐增量并结束分片任务后重试。成功切换通过 MongoDB 单文档条件更新原子发布；旧配置的写入请求返回 `storage_configuration_stale`，应重新取得当前配置再重试。配置面板单字段修改和重置也不能绕过验证。
6. 成功后更新部署环境配置为已核验的新配置。重启仅接受最初的部署配置或当前已核验配置，其他环境修改会阻止启动，避免直接改 `.env` 绕过验收。克隆数据库到其他环境时，不要复制生产的存储迁移状态及文件引用；不能删除生产状态来强行切换。
7. 检查真实下载、鉴权及新上传后保留旧源作为回滚副本，至少保留 30 天恢复窗口再由管理员清理。验收覆盖当前可见对象和已有文件引用，不会跨桶复制历史版本；旧桶中的历史版本仍由原策略保留。接口不会删除旧源，也不会自动永久删除用户原件。

## 故障恢复

应用写入登记 `hostname:pid:token`，并在实际操作结束后解除。请求取消不会提前解除；进程崩溃或数据库清理失败可能留下保守的阻止标记。标记没有 TTL，避免仍在运行的 SDK 上传过期后越过切换保护。它不阻塞普通上传，只阻止迁移。

需要处理遗留标记时，先停止该存储所有写入进程、确认对应进程和 SDK 线程均已退出，处理 `direct_uploads` 中所有未完成任务（含 initializing、active、completing、committing、cleanup）并补齐目标增量；随后由管理员针对 `system_settings` 中 `_id=__settings_atomic__:storage` 清理**已确认失效的** writer token，同时递增 `revision`，再启动服务重新全量验收。不得在进程存活时直接清空数组、重置 revision 或删除配置文档。报告只保留最后一次成功验收的统计和操作者，不按每个文件保存重复日志。

## 控制版本与日志费用

- 原文件桶启用版本控制，历史非当前版本保留 **30 天**；不设置当前用户原件过期规则。保留既有低频分层和未完成分片清理策略，不整桶覆盖生命周期配置。
- 访问日志写入独立私有桶，保留 **14 天**后由云端生命周期自动清理；不要把日志写回源桶形成递归日志。日志桶不再启用无限历史版本或复制审计日志到原文件桶。
- 版本控制会增加被覆盖文件的存储量；上述窗口限制累计量，但不是零费用或永久备份。启用前已丢失的对象仍需从旧桶或其他备份恢复。迁移目标需要单独配置同样的保护，跨服务商按对应原生生命周期实现，不能假设迁移对象会连带迁移桶策略。
- 云端生命周期执行与日志投递是异步的，保留天数不是精确到秒的物理删除保证。禁止为省费缩短当前原件生命周期。
