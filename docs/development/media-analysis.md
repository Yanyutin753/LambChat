# 图片、视频分析与本地预览

图片分析模型须支持视觉。视频分析模型须支持原生视频，并使用 Google 或支持视频的 OpenAI Chat Completions 协议；仅勾选视觉能力不能使 Anthropic 或 Responses 协议支持视频。通过系统设置指定 `VIDEO_ANALYSIS_MODEL_ID`，未指定时回退图片模型并执行相同协议校验。

管理员可在系统设置中调整：

| 设置 | 默认值 | 含义 |
| --- | --- | --- |
| `IMAGE_ANALYSIS_TIMEOUT_SECONDS` | 600 秒 | 图片模型调用的总时限，包含全部重试及退避，最大 3600 秒 |
| `VIDEO_ANALYSIS_TIMEOUT_SECONDS` | 600 秒 | 视频模型调用的总时限，包含全部重试及退避，最大 3600 秒 |
| `FILE_UPLOAD_MAX_SIZE_IMAGE` | 100 MB | 图片上传与分析读取上限 |
| `FILE_UPLOAD_MAX_SIZE_VIDEO` | 200 MB | 视频上传上限 |
| `VIDEO_ANALYSIS_INLINE_MAX_BYTES` | 16777216 字节（16 MiB） | 单个模型请求内的视频预算，超出后重新编码 |
| `VIDEO_ANALYSIS_MAX_BYTES` | 209715200 字节（200 MiB） | 每个视频分析读取上限，可配置至 1 GiB |

已有数据库配置优先于新的默认值。上传上限、分析读取上限和模型供应商请求上限分别生效，base64 传输还会增加约三分之一体积。提高应用上限不能绕过供应商的 HTTP 413 限制；应选择支持对应体积的模型服务。工具失败会以失败状态呈现，不再因返回 JSON 字符串而显示成功。

聊天与工具侧栏中的 `/workspace/...`、当前机器已选工作目录内的 Windows / macOS / Linux 绝对路径和对应 `file://` 媒体引用通过会话绑定的本地/云端沙箱文件接口读取，再生成临时 Blob URL。不会把本地路径拼成网站 URL，也不直接开放 WebView 的本地文件访问。接口继续校验用户、会话、沙箱权限与工作区边界；分享页没有工作区绑定，不能读取本地文件。关闭预览或改变源、账号、会话后释放临时 URL，废弃旧请求。

较大的视频使用运行镜像内的 FFmpeg 重新编码，保留完整时长和音频，不以截断文件满足大小限制；最长边降至不超过 1280 像素，细小文字可能损失。工具结果记录原始大小、实际分析大小及 `compressed`，并告知模型不要推断不可读文字。临时文件在成功、失败和取消后清理。自部署环境须安装 FFmpeg/ffprobe。
