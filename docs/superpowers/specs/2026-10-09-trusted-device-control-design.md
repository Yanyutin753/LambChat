# 云端 Agent 控制电脑：当前设计与安全边界

状态：2026-10-09 用户明确改为云端 Agent 控制电脑，并要求删除无用的本地 Agent 方案。旧的本地模型、独立私有对话、设备 Agent 与模型网关方案不再是交付要求。

## 使用方式

继续使用现有聊天、模型选择、计费、附件和文件面板。桌面应用托管 daemon，用户登录连接后在聊天中选择目标电脑。云端 Agent 生成工具调用，daemon 在目标电脑执行。无需单独配置一套本地模型或创建独立对话。

## 必须满足的边界

- 连接使用 HTTPS，远程明文连接拒绝；凭据绑定完整 origin（含端口），拒绝重定向，服务端工具响应不能更改本机连接配置。
- CUA 只操作用户选择的目标电脑。请求、队列、回传均绑定用户和机器；目标离线或不匹配时失败，禁止静默改机、默认机回退或冒答。
- 确认策略由本机设置并上报，现有审批在服务端通过 ask_human 完成；daemon 接收已授权的执行请求。该审批不能作为抵御平台失陷的独立本机确认保证。操作系统权限限制实际执行范围；凭据撤销后停止新控制请求。
- 禁止将模型文本当作 daemon 配置、可执行插件、更新包或权限变更。更新包独立签名验证，拒绝篡改和回滚。
- 截图、密码字段、工具返回和日志按现有隐私策略处理；HTML 文档预览不能共享原生页面 origin 或调用原生接口。
- 无需控制能力的云端会话继续正常使用；需控制电脑时只访问所选机器，不将本地代码和电脑控制混成模糊的默认目标。

## 如实说明的风险

云端 Agent 控制电脑意味着平台在本机授权范围内拥有操作能力。平台服务器或模型服务失陷可能伪造操作，因此此模式不承诺“平台失陷仍绝对无法控制电脑”。TLS 防止传输窃听与篡改，不能防止已被攻破的合法端点发送恶意指令。完整桌面远控不能通过文件工作目录限制获得全面隔离；独立用户或虚拟机才能提供相应系统边界。2FA 用于账户和敏感授权保护，不替代该执行边界。

## 交付门禁

验证明确选机、离线失败、用户/机器隔离、凭据撤销、拒绝重定向、确认策略与服务端审批、进程取消、密码/截图隐私与更新签名。运行前后端测试、lint/type/build、本地沙箱全量 E2E 与发版压测。所有 PR 经 CI 后集成 develop，staging 真实对话验证后晋升 main、部署生产并回归；正式 release 必须完成 macOS 和现有 Windows 真机安装抽检后再推桌面更新清单。
