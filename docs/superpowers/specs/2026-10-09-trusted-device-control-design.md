# 云端 Agent 控制电脑：当前设计与安全边界

状态：2026-10-09 用户明确改为云端 Agent 控制电脑，并要求删除无用的本地 Agent 方案。旧的本地模型、独立私有对话、设备 Agent 与模型网关方案不再是交付要求。

## 使用方式

继续使用现有聊天、模型选择、计费、附件和文件面板。桌面应用托管 daemon，用户登录连接后在聊天中选择目标电脑。云端 Agent 生成工具调用，daemon 在目标电脑执行。无需单独配置一套本地模型或创建独立对话。

## 必须满足的边界

- 连接使用 HTTPS，远程明文连接拒绝；凭据绑定完整 origin（含端口），拒绝重定向，服务端工具响应不能更改本机连接配置。
- CUA 只操作用户选择的目标电脑。请求、队列、回传均绑定用户和机器；目标离线或不匹配时失败，禁止静默改机、默认机回退或冒答。
- 确认策略由本机设置并上报，现有审批在服务端通过 ask_human 完成；daemon 接收已授权的执行请求。该审批不能作为抵御平台失陷的独立本机确认保证。操作系统权限限制实际执行范围；凭据撤销后停止新控制请求。
- 禁止将模型文本当作 daemon 配置、可执行插件、更新包或权限变更。更新包独立签名验证，拒绝篡改和回滚。
- 截图、密码字段、工具返回和日志按现有隐私策略处理；HTML 文档预览不能共享原生页面 origin 或调用原生接口。
- 无需控制能力的云端会话继续正常使用；需控制电脑时只访问所选机器，不将本地代码和电脑控制混成模糊的默认目标。

## 如实说明的风险

云端 Agent 控制电脑意味着平台在本机授权范围内拥有操作能力。平台服务器或模型服务失陷可能伪造操作，因此此模式不承诺“平台失陷仍绝对无法控制电脑”。TLS 防止传输窃听与篡改，不能防止已被攻破的合法端点发送恶意指令。完整桌面远控不能通过文件工作目录限制获得全面隔离；独立用户或虚拟机才能提供相应系统边界。2FA 用于账户和敏感授权保护，不替代该执行边界。

## 后续 2FA 接入方案

这是后续功能的接入设计，当前版本尚未提供 2FA。复用现有登录、个人设置和电脑选择，避免为 daemon 再建一套身份或模型配置。

优先提供 Passkey 的系统指纹/面容确认，要求服务端验证 user verification；保留认证器 TOTP 与一次性恢复码作为跨端备用。设置时确认一次，正常聊天、已连接电脑的每条工具请求不额外弹 2FA。新设备登录、创建电脑控制 PAT、修改认证因素时要求近期完成的二次验证。[OWASP MFA 指南](https://cheatsheetseries.owasp.org/cheatsheets/Multifactor_Authentication_Cheat_Sheet.html)建议使用具有用户验证的 Passkey，并为恢复和敏感操作设计相应保护。

接入点是 `src/infra/user/manager.py` 登录签发、`src/api/routes/auth/core.py` 登录与刷新、`src/infra/auth/oauth.py` OAuth 回调，以及 `src/api/routes/auth/pat.py` 控制令牌创建。密码或 OAuth 第一阶段通过后，仅签发短期、一次性的专用挑战；挑战不能被当成 access/refresh/PAT 使用。验证第二因素后再签发正常凭据，记录认证时间、方法和账户认证版本。刷新不能提高认证级别，旧会话不能绕过新启用的 2FA；修改因素后使旧会话和待处理挑战失效。

Passkey 绑定服务的精确 HTTPS origin 与 RP ID，禁止任意客户端提供 RP ID。桌面/移动端优先通过系统浏览器完成同一服务 origin 的验证，采用一次性授权码与 PKCE 返回应用，凭据不放进回调 URL；必须分别实测，不能假定 WebView 具备完整 WebAuthn 支持。

TOTP 使用维护中的标准库；种子加密保存，不记录验证码、二维码或种子。按账户与来源限制尝试频率，原子消费验证码的时间步，防并发重放；一次性恢复码只保存不可逆校验值并原子消费。重置因素要求现有因素或严格恢复流程，单独重置密码不能关闭 2FA。[NIST SP800-63B](https://pages.nist.gov/800-63-4/sp800-63b.html#single-factor-otp-verifiers)要求 OTP 有限有效期、仅成功使用一次并限制失败尝试。

交付测试需要覆盖未完成挑战不得访问 API、跨用户/过期/重放挑战拒绝、并发 TOTP 与恢复码只成功一次、旧 refresh/PAT 的失效策略、OAuth 不绕过、因素变更与恢复，以及五语、键盘、错误/加载状态和 Mac/Windows/移动端真实登录。2FA 提高账户安全，不承诺已失陷的平台端点无法控制已授权电脑。

## 交付门禁

验证明确选机、离线失败、用户/机器隔离、凭据撤销、拒绝重定向、确认策略与服务端审批、进程取消、密码/截图隐私与更新签名。运行前后端测试、lint/type/build、本地沙箱全量 E2E 与发版压测。所有 PR 经 CI 后集成 develop，staging 真实对话验证后晋升 main、部署生产并回归；正式 release 必须完成 macOS 和现有 Windows 真机安装抽检后再推桌面更新清单。
