# 按角色配置美元5 小时/周额度

用户已确认按费用额度限制所有用户，配置、扣减和额度展示统一 USD；各角色的金额由管理员配置，不猜测默认金额。

- 复用 RoleLimits，增加 five_hour_budget_usd / weekly_budget_usd。null 不配置，0 禁止调用；同用户多个角色取已配置金额最大值，两周期分别判断。
- 5 小时和 7 天周窗口分别在首次模型调用时开启，各自过期后由下一次调用重开；只查看余额不启动窗口。两个窗口按用户持久化，不绑定自然周、零点或时区。角色变化不清空用户账本，系统启动不覆盖管理员设置。
- 四种协议适配器共享模型调用准入。主/子 Agent、Goal 评分、恢复、定时、渠道和归属用户的辅助调用共用用户余额。独立记忆任务显式绑定所有者，不继承前台回调。
- MongoDB 单用户文档原子检查两个窗口的已结算费用；整数纳美元保存。逐次模型调用结束后等待结算落库，再通知用量刷新，不从累计 trace 再扣费。运行中的 token 用量逐次发布累计快照，落库后更新同一条 usage_logs；终态只更新状态和最终快照。每次调用前已用金额达到任一上限就停止；未知费用保留审计标记，不阻止后续调用，也不算作已确认的零费用。
- 不再估算输入/最大输出费用或要求 token 上限，不做最坏情况预占。旧预占仍可原样结算，但不影响准入及剩余额度。正在执行或并发调用可能在结算后超出额度；后续调用按已结算金额停止。这是逐次检查，不是严格账单硬上限。
- 额度耗尽不删除结果或 checkpoint。Goal 暂停；任务标记可手动恢复，不触发系统重启自动重试。
- 角色编辑/详情与既有用量浮层展示 USD 两周期余额、预占、未知及重置时间，五种语言一致。独立 quota API 仅返回请求者本人数据。
- 系统角色通过专属 quota-only PATCH 更新预算，禁止修改其权限/名称等受保护字段，保留此前不限制并发的语义。
- 语音、图片生成、云端 OCR、付费搜索/抓取、SystemOne、embedding/rerank 等没有可靠美元单价的独立 API，同样先检查已结算额度，未耗尽则放行并记录费用未知；免费网页下载、无 key 免费抓取、本地 OCR 保持可用。外部 MCP 及沙箱/存储/邮件等基础设施费用不在本模型用量账本内。
- 原始供应商计数须有完整性凭证；SDK 将缺字段补成 0 不能证明免费。Anthropic 按流开始的输入与结束的输出合并；缺终结用量、非法计数或未配置的 1 小时缓存写入单价保留未知预占。
- 新账本从功能启用后的调用开始记录，包括未配置预算期间的调用；历史 trace 不再次扣除。模型供应商缺用量不能证明实际账单，未知预占在对应窗口重置后不再限制新窗口。

验证覆盖真实 Mongo 原子并发、重复结算、跨窗口、用户隔离、未知、四协议共享入口、后台所有者、角色保存、API 作用域及 UI 空错状态。所有验证通过共享单进程锁串行执行。

## 审计、重置与重置卡

- 额度读取使用 Mongo 权威角色策略，不依赖可失效的角色缓存。预占以活动窗口键和到期时间作 CAS，窗口切换或管理员重置后重新准入。
- 没有付费归属的调用、同步模型入口继续拒绝；缺价格和 token 上限不再触发准入拒绝。预占前生成 UUID，确认未开始的调用释放预占；重复取消不能中断结算。
- 管理员通过 usage:admin 在用户管理中重置 5 小时或周窗口，也可分别发放用户专属 5 小时卡、周卡。周重置同时恢复 5 小时额度，不额外消耗短期卡；5 小时重置不改变周额度。卡默认有效 30 天，用户主动兑换，只有对应正数额度实际产生已确认消耗时可使用；未知、仅预留、零额度与不限额不消耗卡。旧版未标注类型的通用卡保留耗尽后兑换的兼容规则。
- 手动重置和卡片兑换从操作时刻重开相应的 5 小时/7 天周期；自然过期仍独立、下一次模型调用开启新周期。周卡联动与重开周期依据 [Z.ai 官方 FAQ](https://docs.z.ai/devpack/faq)，不推断自然周到期也联动。
- 采用 Codex 公开 consume 契约语义：幂等请求、reset / alreadyRedeemed / nothingToReset / noCredit 结果，兑换后重新读取额度。一张卡原子重置当前符合条件的窗口；官方未公开的内部策略不作完全一致保证。
- 发卡、兑换、窗口重置与操作记录在单用户文档中原子提交，记录操作者、目标、时间与周期。重复请求不重复发放或消耗；旧调用只结算到原窗口。
- 个人重置卡不写入全局公告。用户用量入口展示卡片数量、有效期与兑换动作；无额度、进行中预留和费用待确认分别呈现。

## 刷新与异常反馈

- 不可用状态收紧为同一行的“暂不可用”和“重试”，五种语言同步；保留可访问状态及繁忙禁用。
- 周期重置和卡片到期时主动刷新，逐次结算、运行结束、重置/发卡通知、重连和重新展开继续复用同一刷新入口；同一时间仅保留一个额度请求。
- 账号变化时重新挂载用量组件，取消旧额度请求并清空卡片兑换的重试状态，避免将旧账号余额带入新账号。
- 读取时验证额度与卡片结构；写入时验证确认结果及新卡身份。空响应或异常确认不能清除幂等重试编号。
- 到期发生在响应途中时补拉一次；重复返回同一过期时间不产生刷新循环。额度读取失败时禁用旧快照中的重置卡操作。
- 调用热路径只返回活动窗口字段及准入结果；清理过期账本不依赖用户打开界面。孤立预占保留至原窗口结束后 7 天供迟到用量核对；无法获知的供应商账单仍标未知，不能宣称为实际零费用。
