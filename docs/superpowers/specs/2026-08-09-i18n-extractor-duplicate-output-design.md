# i18n 提取器重复输出修复设计

## 目标

修复 `frontend/scripts/extract-i18n.ts` 在一次运行中重复报告、重复写入新增翻译键的问题，并将本次生成的两个占位翻译替换为五种语言的实际文案。

## 设计

- 保留提取器现有的“新增英文键使用键路径、其他语言使用待翻译标记”策略，不扩展源码解析能力。
- 删除重复的新增键和写文件流程，使一次提取只产生一次副作用和一组日志。
- 使用临时目录运行真实提取脚本的集成测试，断言单个新键只输出一次新增日志。
- 直接补齐 `chat.messageInput` 与 `documents.wordPreviewTitle` 的 en、zh、ja、ko、ru 文案。

## 验证

- 回归测试先在旧实现上因日志出现两次而失败，修复后通过。
- locale 完整性测试通过。
- 再运行一次 `pnpm i18n:extract`，不新增键、不留下本次键对应的占位符。
