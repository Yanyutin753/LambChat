# 长期助手与持续任务

状态：实现中；以下验收全部完成前不得宣称正式可用。

## 产品目标

用户持续联系同一个助手，同时推进多件事、补充要求、查看结果和处理决策。
助手身份、用户可见讨论、授权任务和底层执行批次分别持久化；模型上下文不是任务数据库。
沿用 LambChat 的模型、角色、Team、工具、审批、后台执行、Goal、调度、沙箱、渠道和用量体系。

## 实现顺序与边界

1. 长期助手身份与租户隔离存储、版本更新；对接现有角色及会话。
2. 持久任务/授权与协调工具，对接现有后台执行与完成事件，不能创建第二套执行队列。
3. 可见助手与活动页面、任务控制、审批和结果，打通真实模型本地闭环。
4. 渠道订阅、主动规则与调度，群聊和记忆范围，故障恢复与费用归属。
5. 完成全部调用方、五语、文档与测试后串行最终验证，真实使用并修复，再将 PR 转为可审阅。

身份配置不包含 API 密钥，不替代实时 RBAC；私聊可读不等于允许向群里披露。
助手暂停、停止单个任务和取消未来规则是不同操作，界面说明各自影响。
任务保持原执行环境；更改助手默认环境不迁移正在运行的任务。
恢复不以重发外部写入解决不确定状态；只有真实投递成功才生成送达收据。
所有验证通过 `scripts/run_validation.py`，worker/job=1；占用即退出。
真实验收使用 `desktop_dev`，保留可回看的对话及产物，凭据和报告放仓库外。

## 研究依据

- [Dots：任务和记忆](https://learn.chatgpt.com/docs/dots/tasks-and-memory)：持续责任、独立任务、跨入口上下文与披露边界。
- [Dots：控制](https://learn.chatgpt.com/docs/dots/controls)：活动检查、任务/调度分别停止。
- [SuperAgent 领域模型](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/main/docs/001-domain.md)：讨论、授权工作、执行批次与订阅分离。
- [SuperAgent 授权](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/main/docs/002-authorization.md)：程序准入、观察模式、上下文不授予权限。
- [DS-Bot](https://github.com/Fei2411/DS-Bot)：长期身份、负责人群聊、分段上下文与记忆范围。

上述资料用于设计参考，不证明 LambChat 已实现或通过验收；不照搬研究原型的本机全权限假设。
