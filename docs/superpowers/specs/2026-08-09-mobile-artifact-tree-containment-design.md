# 移动端文件树防溢出设计

## 目标

“全部文件”面板在手机宽度下展示多层目录或长目录名时，所有目录行必须保持在面板可视区域内；右侧下载和展开/收起按钮始终可见、可操作。

## 根因

`TreeDirRow` 通过递归容器逐层增加左侧缩进，但目录节点与子树容器没有完整建立可收缩的宽度边界。长且不可断行的目录名会参与嵌套树的固有宽度计算，把目录行及其右侧固定宽度操作按钮推到视口之外。

## 界面与布局

- 保留现有文件树层级和桌面端缩进，不改变下载、展开或文件预览交互。
- 目录节点、递归子树及文件列表区域限制在父容器宽度内，并允许 flex/grid 子项收缩。
- 目录名称占用剩余空间并继续单行省略；文件夹图标、下载按钮和展开按钮不收缩。
- 面板内容不产生横向滚动；深层目录不会把祖先或面板撑宽。
- 下载按钮在触屏端维持当前常显行为，在桌面端维持 hover/focus 显示行为。

## 实现范围

只调整 `RevealArtifactsSummary.tsx` 中的文件树宽度约束，不修改数据结构、下载逻辑、翻译键或持久侧栏的公共接口。

## 测试与验收

先增加一个失败的组件回归测试，以长 UUID 目录名和至少两层嵌套目录作为夹具，验证递归树建立了可收缩、受父级宽度约束的布局契约，并且下载按钮仍紧邻展开按钮。随后做最小实现，运行该组件测试、相关前端测试和前端构建。

手机端验收标准：长名称被省略，目录层级仍可辨认，下载与展开按钮均完整位于右边界以内，页面没有横向位移或横向滚动。
