# LambChat 2.5.5 Version Bump Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Synchronize all current LambChat release metadata to version `2.5.5`, document the release, verify consistency, and push one scoped commit to the current `main` branch.

**Architecture:** Keep the existing distributed version metadata model and update only release-bearing fields. Use a fail-first repository assertion followed by focused existing tests and an explicit staged-file allowlist; do not add runtime code or a new permanent test module.

**Tech Stack:** Python 3.12, pytest, TOML/JSON metadata, Tauri/Rust, Capacitor Android/iOS, Git.

---

## Global Constraints

- Target application version: `2.5.5`.
- Release date: `2026-08-09`.
- Android version code: `255`.
- Change only the editable LambChat package version in `uv.lock`; do not change dependency resolution.
- Do not create a Cargo lockfile; this repository does not track one.
- Include the approved design and this implementation plan in the one scoped commit.
- Push the current `main` branch only after verification.
- Do not create or push a tag, publish a GitHub Release, or manually trigger a release workflow.

## File Map

- Modify `pyproject.toml`: Python/application canonical version.
- Modify `uv.lock`: editable LambChat package version only.
- Modify `frontend/package.json`: frontend application version.
- Modify `frontend/src-tauri/tauri.conf.json`: Tauri bundle version.
- Modify `frontend/src-tauri/Cargo.toml`: Rust desktop package version.
- Modify `frontend/android/app/build.gradle`: Android version name and code.
- Modify `frontend/ios/App/App.xcodeproj/project.pbxproj`: iOS Debug and Release marketing versions.
- Modify `CITATION.cff`: release version and release date.
- Modify `CHANGELOG.md`: user-facing `v2.5.5` release notes.
- Include `docs/superpowers/specs/2026-08-09-version-2-5-5-design.md` and `docs/superpowers/plans/2026-08-09-version-2-5-5.md`: approved design and execution record.

- [ ] **Step 2: Run the fail-first release consistency assertion**

Run:

```bash
uv run python - <<'PY'
import json
import re
import tomllib
from pathlib import Path

root = Path.cwd()
expected = "2.5.5"
with (root / "pyproject.toml").open("rb") as f:
    assert tomllib.load(f)["project"]["version"] == expected
with (root / "frontend/package.json").open(encoding="utf-8") as f:
    assert json.load(f)["version"] == expected
with (root / "frontend/src-tauri/tauri.conf.json").open(encoding="utf-8") as f:
    assert json.load(f)["version"] == expected
with (root / "frontend/src-tauri/Cargo.toml").open("rb") as f:
    assert tomllib.load(f)["package"]["version"] == expected
with (root / "uv.lock").open("rb") as f:
    packages = [p for p in tomllib.load(f)["package"] if p["name"] == "lambchat"]
assert len(packages) == 1 and packages[0]["version"] == expected
android = (root / "frontend/android/app/build.gradle").read_text()
assert re.findall(r"versionCode\s+(\d+)", android) == ["255"]
assert re.findall(r'versionName\s+"([^"]+)"', android) == [expected]
ios = (root / "frontend/ios/App/App.xcodeproj/project.pbxproj").read_text()
assert re.findall(r"MARKETING_VERSION = ([^;]+);", ios) == [expected, expected]
citation = (root / "CITATION.cff").read_text()
assert re.search(r"(?m)^version: 2\.5\.5$", citation)
assert re.search(r"(?m)^date-released: 2026-08-09$", citation)
PY
```

Expected: FAIL on the first `pyproject.toml` assertion because it is still `2.5.4`.
