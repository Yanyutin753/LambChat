# 沙箱下载三平台基准

日期：2026-10-09。被测修复：`2de9d905`（Windows 下载命令兼容及流式失败回报）。

## 固定方法

- Windows x64、Linux x86_64、macOS Apple Silicon 均在真实主机执行，不模拟操作系统。
- 两份相同的随机二进制文件：100 KiB（102400 字节）、10 MiB（10485760 字节）。
- 文件从生产使用的对象存储签名 HTTPS 地址下载，三平台共用同一份对象；不使用用户文件。
- 使用 `src/infra/tool/upload_url_tool.py` 的 `_sandbox_download_command` 生成命令，Windows 经 `cmd.exe` 与桌面端 Python shim 执行，Linux/macOS 经系统 shell 执行。
- 每种大小连续运行三次，计时从启动命令到退出，包含网络、解释器启动与落盘；每次核对字节数与 SHA-256，再删除测试文件。
- 失败场景使用无效签名，验证非零退出、旧目标内容保留、临时下载文件清理。
- 测试对象、临时目录与包含签名 URL 的临时脚本用后删除，不提交凭据或签名链接。

## 实测结果

| 平台 | 100 KiB 三次耗时（ms） | 中位数（ms） | 10 MiB 三次耗时（ms） | 中位数（ms） |
| --- | --- | --- | --- | --- |
| Windows x64 | 2288 / 1987 / 2044 | 2044 | 4360 / 4351 / 4533 | 4360 |
| Linux x86_64 | 1427 / 1305 / 1459 | 1427 | 3012 / 2804 / 3158 | 3012 |
| macOS arm64 | 1738 / 1445 / 1485 | 1485 | 3870 / 3975 / 3746 | 3870 |

18 次下载全部大小与 SHA-256 一致。失败场景分别在 Windows 1671 ms、Linux 1289 ms、macOS 1929 ms 内退出；三平台均保留旧目标并清理临时文件。

耗时是本次网络环境的基准快照，不能作为跨地区带宽保证。后续回归应复用相同文件大小、重复次数和校验方式，并记录网络位置、架构及被测提交；明显退化需排查，不能仅放宽超时。

## 覆盖边界

此基准覆盖 URL 下载快路径的真实 shell、HTTPS 和落盘行为，不等同于桌面安装、界面、CUA 操作或三平台 daemon 中继全链路验收。

本次另在 macOS 执行 `scripts/e2e_local_sandbox.py --stress`，52/52 通过，覆盖机器绑定、双向大文件流式传输、501 文件整树搬运及持续并发。异常回报的自定义传输错误、真实 httpx 错误、认证退出与补发失败由针对性测试覆盖；网络完全不可达时，错误结果仍可能无法送达。
