LambChat 是开源 AI Agent 平台：多模型对话、MCP 工具、技能引擎、 持久记忆与生产级部署——一套可自托管的全栈方案。

LambChat 能做什么

Agent 运行时

深度代理图与子代理、思考模式、流式输出，高危操作需人工审批。

MCP 与工具

系统级与用户级 MCP 服务器、密钥加密存储，支持 Daytona、E2B、CubeSandbox 沙箱代码执行。

记忆与技能

跨会话记忆、技能市场、GitHub 同步技能、可复用的人设预设。

多模型对话

自带密钥接入 Claude、GPT、Gemini 等——SSE 流式输出、多模态输入与文档处理。

全栈客户端

React 19 网页端、Capacitor 移动端、Tauri 桌面端、可安装 PWA——全部共用同一后端。

生产就绪

JWT 认证 + RBAC、实时同步、定时任务、用量统计，提供 Docker / Kubernetes 部署方案。

为什么是 LambChat

大多数 Agent 产品止步于「带工具的聊天」。LambChat 为更长的路径而设计：配置模型、安全地连接工具、让 Agent 产出工件、沉淀有用的上下文、分享结果、审批高危操作，并把整套系统交付给真实用户——自托管、开源（MIT）、附中英双语文档。

技术栈

Python 3.12 + FastAPI + LangGraph / deepagents · MongoDB + Redis + arq · React 19 + TypeScript + Vite · Docker / Kubernetes 部署。界面支持中文、English、日本語、한국어、Русский。
